{# ══════════════════════════════════════════════════════════════════════ § 8 METHODOLOGY — consolidated notes (one place) ══════════════════════════════════════════════════════════════════════ #}

Methodology

Page views count only GET requests. Known bots (user-agent filter) are excluded, but stealth bots may still appear in counts.

Unique visitors are counted as distinct hashed IPs per day (SHA-256 with a daily salt — raw IPs are never stored). The same person on different devices or networks is counted separately.

Likely real = session > 1 s OR JS-verified. Likely bot = session ≤ 1 s, no JS verification. Duration histograms exclude single-page visitors (time-on-page is unmeasurable server-side). Session = sum of inter-page gaps ≤ 5 min.

JS-verified percentage indicates views where client-side JavaScript executed — a strong signal of a real browser.

Country data is resolved at request time via GeoIP lookup; only the 2-letter country code is stored.
