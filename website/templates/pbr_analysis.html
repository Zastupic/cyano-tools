Photobioreactor Data Analysis — FMT-150 & MC-1000 Beta

Beta notice: This tool is under active development. Results should be verified independently. Please report any issues.
At a glance: Upload an .ods export file from a PSI FMT-150 photobioreactor or MC-1000 multi-cultivator. Select signals to plot on an interactive time-series chart. OD720 and OD680 readings above the linearity threshold can be corrected automatically; per-channel strain selection is available for the MC-1000. Download the full-resolution dataset with corrected OD columns appended as XLSX.
How to use ▼
  1. Export your experiment data from the PSI control software as an .ods file.
  2. Upload the file using the drop zone below — device type (FMT-150 or MC-1000) is detected automatically from the file.
  3. Use the Signal Selector to choose which channels and signal types to display. For the MC-1000, select individual culture channels (1–8).
  4. If OD720 or OD680 signals are selected and values exceed the linearity threshold (0.4 for OD720; 0.6 for OD680), open the OD Correction panel, choose the appropriate strain (WT or EFE) per channel, and select whether to show the raw signal, the corrected signal, or both.
  5. Logged experiment events are overlaid as vertical lines on the chart (toggle with the Show events checkbox).
  6. Click Download XLSX to export the full-resolution dataset. Corrected OD columns are appended next to the originals.

Note on large files: Files with more than 3 000 rows are automatically downsampled for display. The downloaded XLSX always contains the full-resolution data.

Supported devices ▼
PSI Photobioreactor PBR FMT-150
  • Single-vessel continuous-culture system
  • OD720 + OD680 sensors, actinic lights (Blue/Red), temperature, pumps, fluorescence (Qy, Ft, Fm), pH, O2, CO2 probes
  • OD correction: WT strain (k = 1.83) or EFE strain (k = 1.6376) for OD720
PSI Multi-Cultivator MC-1000-OD
  • 8-channel parallel cultivation system
  • Per-channel OD720 + OD680, multi-wavelength actinic lights (8 × 9 wavelengths), temperature, turbidostat regulation
  • OD correction selectable per channel (WT or EFE strain)

OD correction equations are described in the Calculators page.
