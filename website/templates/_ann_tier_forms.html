Define how per-file metadata is encoded in filenames. Each token decodes one positional segment after splitting the filename stem by the separator (position 0 = first segment, 1 = second, etc.).

Position Field Strip prefix Strip suffix

Example: file ctrl_rep2_t24.txt with separator _ and tokens at positions 0 = treatment_label, 1 = bio_rep (prefix rep), 2 = timepoint (prefix t) → treatment_label=ctrl, bio_rep=2, timepoint=24.
