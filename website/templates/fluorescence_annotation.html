Fluorescence Data Annotation

At a glance: Upload raw OJIP fluorescence files, fill in experiment metadata once (per investigation / study / assay), then review and complete the auto-populated reconciliation grid. Download the annotated dataset as a MIAPPE-compatible ZIP bundle containing metadata, JIP-test parameters, and raw transient data in Parquet format.
  1. Fill in experiment metadata — Enter information common to all files in the Investigation, Study, and Assay tabs below. Use Filename tokens to define a per-file decoding pattern if your filenames encode sample information (e.g. ctrl_rep1_t0.txt).
  2. Upload fluorescence files — Drag & drop or click to select one or more OJIP transient files (.csv or .txt). Supported instruments: MULTI-COLOR-PAM / Dual-PAM (Walz), AquaPen/FluorPen, FL6000.
  3. Review the reconciliation grid — Each row is one file. Cells are colour-coded by provenance: H auto-detected from file header, F decoded from filename, I inherited from your tier forms, C computed (JIP-test), T typed by you. Click any editable cell to override a value.
  4. Download the bundle — Click Download bundle to save a ZIP file containing MIAPPE metadata, JIP-test parameters, and the full dataset as Parquet. Reload it any time with Load bundle.
