Fluorescence Data Annotation

At a glance: Upload raw OJIP fluorescence files, fill in experiment metadata once per tier (Investigation / Study / Treatment / Fluorometer settings), then review the auto-populated reconciliation grid. Download a MIAPPE-compatible ZIP bundle containing per-curve JSON sidecars and a one-row-per-curve summary.parquet.
  1. Fill in experiment metadata — Enter information common to all files in the Investigation, Study, Treatment, and Fluorometer settings tabs below. Use Filename tokens to decode per-file metadata from filenames (e.g. ctrl_rep1_t0.txt).
  2. Upload fluorescence files — Drag & drop or click to select one or more OJIP files (.csv or .txt). Supported instruments: MULTI-COLOR-PAM / Dual-PAM (Walz), AquaPen/FluorPen, FL6000. Alternatively, download an XLSX template to pre-fill metadata in a spreadsheet, then upload the filled workbook.
  3. Review the reconciliation grid — Each row is one curve. Cells show a coloured left-border stripe and a corner glyph by provenance: ✞ typed ≡ file header ⌗ filename ⤓ inherited # computed + missing. Use ↧ in column headers to fill a value down to all visible rows. Keyboard: Enter = commit + move down, Tab = commit + move right, Esc = cancel.
  4. Download the bundle — Click Download bundle to save a ZIP with per-curve annot_*.json sidecars + summary.parquet. Reload any time with Load bundle.
XLSX template format: The downloadable template is a multi-sheet workbook with one sheet per metadata tier (Investigation, Study, Fluorometer, Treatments, Per-curve). Each sheet has header columns matching the field labels; cells with dropdown validation are pre-configured for vocabulary fields. Fill in the template in any spreadsheet application, then upload the .xlsx file to populate tier forms and per-curve overrides.
